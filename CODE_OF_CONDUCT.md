# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, critique ideas rather than people, and do not publish another person's private notes, credentials, or vault paths. Maintainers may remove comments or contributions that violate these expectations.

Report conduct concerns privately to the maintainers through the repository profile. Reports will be reviewed confidentially.
